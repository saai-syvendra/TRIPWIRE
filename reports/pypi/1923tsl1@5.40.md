# pypi 1923tsl1@5.40

**Source:** pypi_malregistry · **Source label:** malicious · **Released:** not found · **Assessment:** malicious (high) · **Analysis:** ai (claude-opus-5-5)

## Summary

The payload sits at module top level in `setup.py`, so it runs whenever pip builds the sdist (setuptools backend). One gate (`g1`) wraps it: `os.getlogin()` must differ from the author's own login (value redacted), which holds for practically every victim. Behind it the code writes a HKCU `RunOnce` value pointing at `%TEMP%\temp-PipInstall.exe`, downloads an executable from a Dropbox link into that path with `%WINDIR%\System32\curl.exe`, and runs it with `os.system`. Everything is Windows-only and wrapped in a bare `except: pass`.

## Execution

- **setup_py** `python setup.py (pip install from sdist)`: runs setup.py; direct_script, download_then_exec; errors hidden.

## Gates

| gate | hook | expression | branch | min | behaviours | recipe |
|---|---|---|---|---|---|---|
| g1 | setup_py | c1 (c1: username != <author handle, redacted>) | then | 1 | persistence, download, exec_downloaded | os=win32; username=developer |

Gate intent: g1 activate/enables/targeting

Grounding: 1 of 1 conditions and 1 of 1 gates from the candidate set.

## Requirements

- os: win32 (Uses subprocess.CREATE_NO_WINDOW, reg add on HKCU RunOnce, %WINDIR%\System32\curl.exe and runs a downloaded .exe.)
- other: env var TEMP set (Drop path is built from os.environ['TEMP'] outside the try; missing TEMP raises KeyError and stops setup.py.)
- file_present: %WINDIR%\System32\curl.exe (The download is done by calling curl.exe at this fixed path (needs env var WINDIR set too).)
- network: dl[.]dropboxusercontent[.]com:443 (Second-stage executable is fetched from a Dropbox share link.)

## Behaviour

- Ungated: none
- Gated: persistence, download, exec_downloaded

## Notes

- Windows is a requirement, not a gate: there is no OS check, but `os.environ['TEMP']` is read outside the try, so on hosts without `TEMP` setup.py raises KeyError, and the rest fails silently off Windows.
- `os.getlogin()` may raise with no controlling terminal, which aborts setup.py before the payload. A scanner should provide a login session.
- The RunOnce value is written before the file is downloaded; it still gives one-shot persistence for the next logon.
- Family hint comes from the dropped file name in the URL (`esqueleDrp.exe`); comments name a group, not used as evidence.
