# pypi 11Cent@999.0.2

**Source:** pypi_malregistry · **Source label:** malicious · **Released:** not found · **Assessment:** malicious (high) · **Analysis:** ai (claude-opus-5-5)

## Summary

The sdist overrides the setuptools `install` command (`CustomInstall`), so its `run` method executes on a normal pip install of the sdist. After calling the stock install, it collects hostname, current directory and username and sends them in three GET requests to j0j0[.]xyz hosts (one puts hostname and username into a subdomain, DNS-style exfil). It then POSTs the contents of `/etc/passwd` and `/root/.bash_history`. There are no gates: every step runs unconditionally.

## Execution

- **cmdclass** `cmdclass[install] = CustomInstall`: runs setup.py; direct_script.
- **setup_py** `python setup.py (pip install from sdist)`: runs setup.py; direct_script.

## Gates

None.

## Requirements

- other: python package requests importable in the build environment (setup.py imports requests at top level but declares no build requirement; under pip build isolation the import likely fails before setup() runs)
- network: j0j0[.]xyz:443, 11cent[.]j0j0[.]xyz:80, <hostname>.<username>.j0j0.xyz:80 (uncaught requests calls; a failed GET aborts the later /etc/passwd and history uploads)
- file_present: /etc/passwd (read unconditionally and uploaded)
- file_present: /root/.bash_history (read unconditionally and uploaded; open raises if it is missing)
- privilege: root_or_admin (/root/.bash_history is normally only readable by root)
- os: linux (hardcoded Unix paths /etc/passwd and /root/.bash_history)

## Behaviour

- Ungated: recon, exfil
- Gated: none

## Notes

- No error handling, so a failed request or an unreadable `/root/.bash_history` (non-root install) raises and stops the remaining steps. The history upload effectively needs root.
- `requests` is imported at the top of setup.py with no declared build requirement, so under pip build isolation setup.py would likely fail at import before anything runs.
- Version 999.0.2 points to dependency confusion. The domain looks derived from the author handle, so no family hint is given (rule 5).
