# pypi 15Cent@999.0.1

**Source:** pypi_malregistry · **Source label:** malicious · **Released:** not found · **Assessment:** malicious (high) · **Analysis:** ai (claude-opus-5-5)

## Summary

The sdist overrides the setuptools `install` command (`cmdclass={'install': CustomInstall}`), so `CustomInstall.run` runs on a normal pip install after the real install step. It tries to touch a marker file at `/root/j0j0.poc`, lists `/run`, `/etc`, `/home`, `/mnt` and `/rasp`, and POSTs each listing with the hostname and username in the URL to hxxps://j0j0[.]xyz/lists/. It then reads `/.dockerenv`, `/root/.wget-hsts` and a Docker container config path and POSTs their contents to the same host. There are no gates; the file reads are unguarded, so outside a root Docker container the run stops with an exception at the first missing file, after the listings have already been sent.

## Execution

- **cmdclass** `cmdclass[install] = CustomInstall`: runs setup.py; direct_script; errors hidden.
- **setup_py** `python setup.py (pip install from sdist)`: runs setup.py; direct_script.

## Gates

None.

## Requirements

- network: j0j0[.]xyz:443 (all directory listings and file contents are POSTed over HTTPS to this host)
- other: python module requests importable in the build environment (setup.py imports requests at top level and uses requests.post for every send)
- file_present: /.dockerenv (read unconditionally before the file exfil posts; absence raises and stops the rest)
- file_present: /root/.wget-hsts (read unconditionally for the second file post)
- privilege: root_or_admin (the /root marker write and /root/.wget-hsts read need root)
- os: linux (all paths are Linux/Docker paths)

## Behaviour

- Ungated: recon, exfil, write_file
- Gated: none

## Notes

- The try/except blocks around the directory listings only substitute placeholder text, so they are not gates.
- The Docker config path contains the literal `container-id` placeholder, so that last read and post almost never succeed.
- Version 999.0.1 and the "Exfiltration" description suggest a dependency-confusion probe; the endpoint domain is named after the author handle, so no family hint is recorded.
