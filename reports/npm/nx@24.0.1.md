# npm nx@24.0.1

**Source:** benign_sample · **Source label:** benign · **Released:** 2026-10-23 (registry) · **Assessment:** benign (medium) · **Analysis:** ai (claude-opus-5-5)

## Summary

The `postinstall` hook runs `node -e` to require `dist/bin/post-install.js` inside a try/catch, so errors are swallowed. A 30 s watchdog exits the process if the step hangs. The script acts only when this copy is the workspace's main `nx`, `nx.json` exists in the workspace root, and Nx Cloud is in use: `NX_NO_CLOUD` is not `true`, nx.json does not set `neverConnectToCloud`, and either an `NX_CLOUD_AUTH_TOKEN`/`NX_CLOUD_ACCESS_TOKEN` env var is set or nx.json configures Nx Cloud (g1). When all of that holds, it asks the Nx Cloud API (default cloud.nx[.]app) to verify the cached client bundle. If the server says the bundle is not valid, it downloads a tarball, extracts it into the cache, deletes old bundles and requires the new client (g2). Importing the modules also copies the platform native binding into a tmp cache and loads it, with no gate.

## Execution

- **postinstall** `node -e "try{require('./dist/bin/post-install')}catch(e){}"`: runs dist/bin/post-install.js; inline_eval, download_then_exec; errors hidden.

## Notes

- This is the stock Nx postinstall. No credential reads, exfiltration or injected code were found on the install path.
- All 200+ prefilled candidates come from module-load plumbing and were dropped: the NAPI-RS native binding picker, the WASI fallback, cache folder selection, and config defaults. The real gates are out of set, which forces manual review.
- c2, c4 and c7 test the consuming workspace's `nx.json`, so they are recorded as `consuming_app` (out of scope). A Phase 2 VM would need an Nx workspace with an `nx.json` plus a cloud token to reach the download.
- c8 is the Nx Cloud server's `valid` flag (`server_response`).
- The witness for the extract `createWriteStream` goes through a tar-stream `entry` callback, so it is marked `dynamic_dispatch`.
- Coverage: the core install path was read in full. The many other modules reached by import were audited by grep for module-level side effects rather than read line by line.
